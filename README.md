# 🧠 My Problem Solving Framework

Every problem in this repository follows the same structured workflow.

---

## 🟢 Phase 1 — Understand the Problem

Before writing any code, I focus on understanding the problem completely.

✔ Read the problem carefully

✔ Analyze the constraints

✔ Dry run the given examples

✔ Understand what the problem is actually asking

✔ Find the intuition behind the solution

---

## 🟡 Phase 2 — Design the Solution

Once the intuition is clear, I design the algorithm.

✔ Think of the brute-force approach

✔ Optimize it

✔ Write pseudocode

✔ Decide the required data structures

✔ Estimate Time & Space Complexity

---

## 🔵 Phase 3 — Implement

Now it's time to convert the algorithm into C++.

✔ Write clean code

✔ Prioritize correctness

✔ Improve readability

---

## 🟣 Phase 4 — Dry Run

Before submitting, I manually execute the algorithm.

✔ Trace every variable

✔ Verify each iteration

✔ Ensure the logic works as expected

---

## 🔴 Phase 5 — Edge Cases

Finally, I test my solution against special cases.

Examples:

- Empty input
- Single element
- Duplicate values
- Negative numbers
- Already sorted input
- Maximum constraints
- Minimum constraints

If necessary, I refine the solution before submission.
